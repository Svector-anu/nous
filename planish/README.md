## Core Vision
A live, never-pausing world where hundreds of AI agents with personalities freely build settlements, form clans, wage wars, and create emergent history. Most of the world stays lightweight. Key places (cities, fortresses, battle zones, landmarks) use high-fidelity pure-procedural 3D (realistic walls & houses, zero art assets). Users deploy custom agents. Public live viewer. then when everything works we wire  prediction markets and token chaos. Start near $0 cost with free tools.
